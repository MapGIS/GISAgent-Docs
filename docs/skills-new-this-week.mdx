## 新增一：`atlas-earth`（GitLab subgroup）

### 技能定位

`atlas-earth` 是真实三维城市场景技能：用 Atlas 渲染器把 Overture 城市数据做成可在 GIS Agent 内预览的
Cesium 三维页，覆盖建筑、道路、水系、树木、路灯与夜景光照。两种工作模式：

- 用户给了地点或范围：按 bbox 或 `--clip` 多边形下载 PMTiles 并裁切，输出指定范围的三维实景页；
- 用户没给地点：输出探索页，让用户在城市样例之间切换。

它定位于“真实城市三维场景”本身；只要建筑高度、天际线或容积率专题时应当走 `3d-building-map`，
两者在同一天都发生了更新，注意分流。

## 改名（非新增）：`tianditu-1m-atlas`

`sld-tianditu-gb100` 于 2026-10-22 改名为 `tianditu-1m-atlas`。技能能力已从单一底图扩到“三套底图＋
两套水系专题＋地质 overlay”、省域遮罩、统计卡与电子／传统版面，原名不再能说明它。

- 改名顺序是硬约束：先改 GitLab 项目路径，再改本地目录与 `origin`，最后同步；否则下次同步会按远端旧名重拉。
- 结果：推送 `b6e02ae..067c3b8`；同步 pull 51／失败 0，清单自动刷新；本机与 5 个运行容器只有新目录，
  旧名 `sld-tianditu-gb100` 已不在卷内。
- 历史边界：技能 2026-10-08 起本地暂存、2026-10-18 建 GitLab 仓库，因此**不是本周新增**；
  历史同步报告与热更新记录保留旧名。
- 遗留：阿里云栈目录与卷仍是旧名，下次 L0 热更新要“新增新目录＋移除旧目录”，否则线上并存两份同内容技能。
